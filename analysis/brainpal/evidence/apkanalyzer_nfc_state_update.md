## Path

The overlay callback for “Use other options” is handled by `he.f0.b` case 4. It logs `BLOCK_REELS_NFC_LIMIT_DONE_CLICKED`, writes the current time to `last_limit_respected_at_v1`, invokes the injected `xd.h.a()` use case, and emits `CloseOverlay(resumeReels=false)`. The UI label says NFC, but the handler contains no challenge-selection call.

The selected `xd.h` branch launches an `xd.g` coroutine, which calls the `ud.e` update flow with an `xd.f` coroutine. That coroutine reads the current `wd.a` blocking record. If a record exists, it copies the record with a new update time and these changes:

- `isBlockEnabled = true`
- `blockPauseExpiryTime = null`
- `blockStartTimestamp = null`
- `hardBlockValidTill = null`
- `blockStartReelCount = null`
- `updatedAt = currentTimeMillis`

It preserves the record's user ID, allowed reel count, cooldown, and allowed-window duration. If no record exists, the code instead creates a new enabled record using current/default blocking configuration and the current time.

The obfuscated `wd.a` field mapping is established by `u0.d2`, which copies those fields into the named `UserBlockingConfig` model, and by that model's constructor:
