## `Exit Reels`

The string resource is `block_reels_overlay_close` (“Exit Reels”). The `ck.n` UI callback dispatches `he.g`. In `he.f0.b`, that event logs `BLOCK_REELS_OVERLAY_CLOSE_CLICKED` (`kc.a.a7`) and launches `he.d0` case 3. That coroutine emits `he.a(false)`, whose type string is `CloseOverlay(resumeReels=false)`. This path does not write `last_limit_respected_at_v1`.

## NFC `Use other options`

The string resource is `block_reels_nfc_locked_overlay_unlock_key_cta` (“Use other options”). Its callback dispatches `he.i`. In `he.f0.b`, this event logs `BLOCK_REELS_NFC_LIMIT_DONE_CLICKED` (`kc.a.k7`) and launches `he.d0` case 4. That coroutine writes the current time to `last_limit_respected_at_v1`, calls the ViewModel dependency's `Lxd/h.a()`, and emits `he.a(false)` / `CloseOverlay(resumeReels=false)`. The traced handler contains no challenge-selection call; it follows the close-event path despite the label.

## Event receiver and Activity callback

The overlay composition collects the ViewModel event flow through `df.p`. For `he.a`, the collector extracts the `resumeReels` boolean and calls the Activity callback. The generated callback bridge in `g1.m1` sends the local broadcast action `BRAINROT_ACCESSIBILITY_ACTION` with `PLAY_MEDIA` when the boolean is true and `PERFORM_BACK` when it is false, then calls `Activity.finish()`.

`ReelsAccessibilityService` registers `uj.h` for that local broadcast. Its `PERFORM_BACK` branch launches `uj.j` case 5. That coroutine delays 500 ms, then checks the service's static `i0` flag and, if true, calls `performGlobalAction(1)` (`GLOBAL_ACTION_BACK`). `i0` is set true in `onServiceConnected` and false in `onDestroy` and `onUnbind`.

The `PLAY_MEDIA` branch calls the Kotlin default-argument helper `ReelsAccessibilityService.d(service, null, 2)`. Here `2` is a default-argument mask, not an action mode. The helper supplies a 500 ms delay and no completion callback. The `dd.d` coroutine then checks `i0`; if the service is active, it builds an accessibility gesture at the screen center with a 50 ms stroke and dispatches it through `AccessibilityService.dispatchGesture`. This is a synthetic center-screen tap attempt, not a media-key command. Static code does not establish what the foreground app does with the tap.

These paths resolve the static callback semantics, but neither action was observed at runtime. The trace does not establish whether the back action exits the media feed as intended or whether the center tap resumes, pauses, or otherwise affects media.

The `he.h0` enum declares NFC, PHONE_JAIL, THUMB_DETOX, FOREHEAD_SCAN, WALK_STEPS, JUMP_COUNT, and SCROLL. The default `he.i0` list contains six types and omits THUMB_DETOX; it filters NFC based on device NFC support and a feature flag. The resource/UI extracts also contain “Allow %1$d Reels” and “Unlocks in.”

The live RM attempt reached the promotional paywall before the block overlay appeared. No live overlay launch or control click was observed. The control conclusions above are static only.
